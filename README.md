# Media Production OS — AI & Automation Suit
An AI-powered media production and operations management system designed to streamline production workflows, staff operations, commercial script generation, rate calculations, and advertiser onboarding.

## Features

- AI Commercial Script Generator
- Advertising Rate Calculator
- Operations & Staff Management
- Advertiser Onboarding Portal
- n8n Workflow Automation
- Gemini AI Integration
- Security Gate
- Production Workflow Management

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome
- n8n
- Google Gemini API

## Project Structure

- `index.html` — Security Gate
- `dashboard.html` — Main Dashboard
- `operations.html` — Operations & Staff Management
- `ai-tools.html` — AI Script Generator & Rate Calculator
- `contact.html` — Advertiser Onboarding Portal
- `style.css` — Application Styling

## Project Overview

Media Production OS is designed to bring media production operations, AI-powered script generation, advertising rate estimation, and business workflow automation together in one platform.

The project demonstrates the integration of AI tools and automation workflows to support media production teams and advertising operations.
